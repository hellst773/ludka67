# RolesMod (ДрузьяMod) — up67

Minecraft 1.20.1, Forge, Java 17.

## Суть мода (как в оригинале Upgrader)

Блок **Апгрейдер**. Крафтится из золота, алмазов и наковальни (рецепт ниже).

ПКМ по блоку → открывается GUI с двумя слотами:

1. **Левый слот** — предмет, который реально тратится и улучшается.
2. **Правый слот** — "образец" желаемого предмета: кладёшь туда ОДИН экземпляр
   того, что хочешь получить (например, алмазный меч). Этот предмет **не
   тратится** — он просто подсказывает моду, какую цель ты выбрал. Так можно
   выбрать вообще любой предмет из игры, не открывая отдельный каталог.

Жмёшь **ПРОКАЧАТЬ x1** (или x2/x4/x8, чтобы прогнать сразу несколько штук
из левого слота за один клик) — мод считает шанс и решает, превращается
предмет в целевой или сгорает.

**Апгрейд бесплатный** — платишь только самим предметом, никакого
дополнительного материала не требуется.

## Как считается ценность и шанс

Ценность предмета не прописана вручную — она вычисляется из настоящих
рецептов: крафт на верстаке, печь, доменная печь, коптильня, костёр,
камнерез. Мод рекурсивно разворачивает рецепт до сырья (железный слиток
стоит как его руда, алмазный меч — как 2 алмаза + палка и т.д.) и берёт
самый дешёвый путь, если рецептов несколько.

Для netherite-апгрейдов (кузнечный стол) значение прописано вручную
(алмазный предмет + слиток незерита + шаблон апгрейда) — разбирать рецепт
кузнечного стола по компонентам средствами API сложнее, чем обычный крафт.

Для предметов без рецепта (руда, кости, эндер-жемчуг и т.д.) используется
заранее заданное "сырьевое" значение (см. `ValueCalculator.java`, блок
`static { base(...); }`). Если и этого нет — берётся оценка по редкости
(`Rarity`: COMMON/UNCOMMON/RARE/EPIC).

**Шанс успеха** = ценность входного предмета / ценность целевого, но не
ниже 2% и не выше 95% (чтобы даунгрейд не был гарантированной победой,
а апгрейд никогда не был совсем безнадёжным).

Предметы, чья ценность целиком в NBT (зелья, зачарованные книги, яйца
призыва, головы игроков, карты, боеприпасы с эффектами, рожки коз,
подозрительное рагу, книга знаний, связки) **исключены** — их нельзя ни
апгрейдить, ни выбрать целью (см. `NbtBlacklist.java`).

## Шутки

Пул фраз на успех/провал — в `JokeMessages.java`. Там же "мемный" текст,
когда апгрейд удался при маленьком шансе, и сводка для x2/x4/x8 ("3 из 8
апгрейдов прошло успешно" и т.п.). Правь списки `FAIL`/`SUCCESS`/
`MEME_SUCCESS` — просто добавляй строки через запятую.

## Рецепт крафта

```
G D G
D A D
G D G
```
G = золотой слиток, D = алмаз, A = наковальня.

## Сборка через GitHub (без своего компьютера)

В репозитории уже лежит `.github/workflows/build.yml` — GitHub Actions сам
соберёт мод при каждом пуше.

1. Создай новый репозиторий на GitHub.
2. Залей туда содержимое этой папки целиком (включая скрытую `.github`
   — надёжнее всего через `git push`, drag-and-drop в браузере иногда
   пропускает скрытые папки).
3. Вкладка **Actions** → сборка "Build mod" запустится сама.
4. Когда появится зелёная галочка — зайди внутрь → раздел **Artifacts** →
   скачай `RolesMod-jar` (там .jar мода).
5. Если красный крестик — открой лог шага "Build mod jar" и пришли мне
   текст ошибки.

Минимальные команды с нуля:
```
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/ТВОЙ_НИК/ТВОЙ_РЕПО.git
git push -u origin main
```

## Сборка на своём компьютере (альтернатива)

1. Установи JDK 17.
2. Скачай `gradlew`/`gradlew.bat`/`gradle/wrapper/*` из официального Forge
   MDK для 1.20.1-47.3.0 (https://files.minecraftforge.net/) и положи поверх
   этого проекта — в zip их нет (среда без доступа к services.gradle.org их
   не генерирует).
3. `./gradlew build` (Linux/macOS) или `gradlew.bat build` (Windows).
4. Готовый .jar — в `build/libs/`.

## Где что лежит

- `up67.rolesmod.RolesMod` — точка входа, регистрация реестров.
- `up67.rolesmod.block.UpgraderBlock` — блок, открывает GUI по ПКМ.
- `up67.rolesmod.menu.UpgraderMenu` — логика слотов, кнопок, самого апгрейда.
- `up67.rolesmod.client.UpgraderScreen` — визуальная часть GUI.
- `up67.rolesmod.upgrade.ValueCalculator` — расчёт ценности по рецептам.
- `up67.rolesmod.upgrade.NbtBlacklist` — какие предметы нельзя апгрейдить.
- `up67.rolesmod.upgrade.JokeMessages` — шутки на успех/провал.

## Текущие упрощения относительно оригинала

- Нет отдельного экрана-каталога со списком/поиском всех предметов —
  вместо этого правый слот принимает "образец" любого предмета напрямую.
  Функционально результат тот же (любой предмет можно выбрать целью), но
  без красивого листания каталога.
- Нет анимированного "колеса" с бегунком — шанс показывается числом в
  процентах и разыгрывается мгновенно по нажатию кнопки.
- Нет кнопок-фильтров 30%/50%/70% (поиск целей по диапазону шанса) и
  экрана настроек (house edge, лимиты попыток, свои цены и т.д.) —
  при желании могу добавить отдельным шагом, это самостоятельные куски кода.
- Текстуры блока/GUI переиспользуют ванильные (наковальня) — если нужна
  своя картинка, пришли PNG, вставлю.

## Производительность / нюансы

`ValueCalculator` кэширует результат на предмет (один раз посчитал — дальше
берёт из кэша), но кэш общий на сессию сервера/клиента и не чистится сам
при смене датапака в той же сессии. Если добавишь кастомные рецепты через
датапак и цены не обновятся — перезапусти мир/клиент (или дерни
`ValueCalculator.clearCache()` из консоли/кода).
